# ARTA — GitHub Pages

1. در GitHub یک repository جدید بسازید (مثلاً `arta`).
2. فایل‌های `index.html`، `catalog.json` و پوشه `images` را آپلود کنید.
3. Settings > Pages > Source: Deploy from a branch > main / root > Save.
4. بعد از ۱–۲ دقیقه آدرس `https://USERNAME.github.io/arta/` آنلاین می‌شود.

## ویرایش محصولات
فایل `catalog.json` را در GitHub ویرایش کنید (آیکون مداد) و Commit بزنید.
هر محصول: id, cat, name, desc, price (تومان), stock, best (true/false), imgs (مثلاً ["images/p1.jpg"]).
برای حذف یک محصول: `"deleted": true`.
کد تخفیف: در settings.discounts.
اطلاعات کارت و تلگرام: در settings.

## محدودیت‌ها
پنل مدیریت و ذخیره سفارش در این نسخه نیست؛ سفارش‌ها فقط از طریق تلگرام می‌رسند.
